# Valora Group — Avalúos e inspecciones de empresas

Landing page para **Valora Group / Matamoro Group**, empresa de avalúos profesionales e inspecciones de empresas. Presenta los servicios de valuación (residencial, terrenos, edificios, plantas industriales) y capta solicitudes de cotización.

## Características

- Diseño *responsive* con menú móvil.
- Barra de navegación que cambia de estilo al hacer scroll.
- Contadores animados de indicadores (avalúos emitidos, años de experiencia, etc.).
- Formulario de solicitud rápida de avalúo.
- Secciones de servicios, sectores atendidos, proceso de trabajo y empresa.
- Sitio 100 % estático.

## Tecnologías

HTML5 · CSS3 · JavaScript vanilla

## Estructura

```text
index.html    Página principal
styles.css    Estilos
script.js     Navegación, contadores y año dinámico
```

## Ejecución local

Abre `index.html` en el navegador o usa un servidor estático (`npx serve .`).
